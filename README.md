# Project *third-party enhancements*

Copyright © 2023–2026 Markus Kohm <komascript at gmx.info>

----------------------------------------------------------------------------

Until August 2026, this was the home of the LaTeX packages

 * [`floatbytocbasic`](https://codeberg.org/komascript/floatbytocbasic),
 * [`floatrowbytocbasic`](https://codeberg.org/komascript/floatrowbytocbasic),
 * [`lscapeenhanced`](https://codeberg.org/komascript/lscapeenhanced),
 * [`scrhack`](https://coderberg.org/komascript/scrhack)
 * [`setspaceenhanced`](https://codeberg.org/komascript/setspaceenhanced),
 * [`standardsectioning`](https://codeberg.org/komascript/standardsectioning).

However, maintaining the packages in a single repository proved to be impractical. Therefore, as a first step, I moved the individual packages (except for `scrhack`) to Codeberg as independent repositories and integrated them here solely as Git submodules. In a final step, `scrhack` was also moved to its own repository on Codeberg.

This repository is now available solely for historical reasons. You can also find the older releases here. Future releases will be published exclusively on Codeberg—in addition to [CTAN](https://www.ctan.org). All development has also been moved there.

As a result, all six packages now have their own issue trackers. Further information can be found via the links to the individual projects provided above.
